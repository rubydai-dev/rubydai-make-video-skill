Bắt đầu một phim

Mỗi phim là một thư mục riêng. Mở thư mục trống trong agent, viết ý tưởng, rồi duyệt ở từng checkpoint.

1

Mở một thư mục trống

Claude desktop app → tab Code, VS Code → panel Claude Code, hoặc trong terminal:

mkdir phim-cua-toi && cd phim-cua-toi && claude
2

Viết ý tưởng

Một câu là đủ. Chọn sẵn một style từ thư viện nếu bạn đã biết mình muốn look nào; phần chưa chắc cứ để trống, agent sẽ hỏi.

3

Chọn chế độ, duyệt, nhận phim

Agent hỏi chế độ (Quick/Film) và mục đích, vài câu ngắn có đáp án gợi ý ★. Phim hoàn chỉnh nằm ở gốc thư mục dưới tên <tên phim>.mp4, kèm file credit.

Cài đặt

Cần Node.js 22+, Python 3.9+, ffmpeg và Google Chrome (hoặc Chromium/Edge). Installer báo phần còn thiếu kèm lệnh cài; agent cũng cài giúp sau khi bạn đồng ý.

Bằng installer (không cần gõ lệnh)

  1. Trên GitHub chọn Code → Download ZIP rồi giải nén (hoặc git clone).
  2. macOS: chuột phải setup.command → Open.
  3. Windows: nháy đúp setup.bat (SmartScreen: More info → Run anyway).
  4. Linux: bash setup.sh.

Installer link kit vào ~/.claude/skills/rubydai-make-video-skill và chạy lại bao nhiêu lần cũng được.

Bằng tay

Tên thư mục phải là rubydai-make-video-skill. Chỉ cài ở một chỗ, rồi mở chat mới.

# Claude Code
ln -s /đường/dẫn/tới/rubydai-make-video-skill ~/.claude/skills/rubydai-make-video-skill

# Cursor
ln -s /đường/dẫn/tới/rubydai-make-video-skill ~/.cursor/skills/rubydai-make-video-skill

Skill tự kích hoạt khi bạn nói "phim ngắn", "làm video", "video sản phẩm", "MV", "make a short film"… Giọng đọc: Gemini (có gói miễn phí), ElevenLabs, hoặc giọng chạy trên máy (VieNeu-TTS cho tiếng Việt, edge-tts, VOICEVOX).

Phim điện ảnh

Một câu chuyện, cảm xúc hay tác phẩm nghệ thuật trông như được quay: độ sâu trường ảnh nông, đặc tính ống kính, grain; âm thanh dẫn dắt bằng môi trường.

Quảng cáo & sản phẩm

Một phim chỉ thuộc về một thương hiệu: màu, font, logo, UI hero shot, end card có lời kêu gọi; xuất 9:16, 1:1 và 16:9 có vùng an toàn.

Dùng một style

Mỗi style là một công thức: bản chất và điều nó không phải, chất liệu, màu, chữ, chuyển động, máy quay, âm thanh và các lỗi hay gặp. Agent chỉ đọc công thức của style được chọn.

Gọi thẳng tên

Copy câu lệnh từ thẻ trong thư viện, hoặc viết style watercolor trong ý tưởng. Agent đọc styles/watercolor.md và dựng theo đó.

Gọi theo tên quen

"Kiểu Vox", "Ghibli", "bản tin thời sự", "phân tích bóng đá"… được tra trong aliases.json ra các style gần nhất. Tên gọi chỉ là ngữ pháp hình ảnh, không bao giờ sao chép tác phẩm.

Để agent gợi ý

Bỏ trống phần style: agent đưa một bảng sáu poster khác nhau theo ý tưởng của bạn để chọn bằng mắt.

python3 tools/styles.py suggest "<ý tưởng>"

Thư viện style

Poster và phim demo là của dự án gốc lemo-opuscar (LemoLab), chỉ để tham khảo khi chọn: phim của bạn dùng cùng ngữ pháp, không bao giờ dùng khung hình của demo. Các style gắn nhãn Của kit là công thức riêng của rubydai, poster vẽ hoàn toàn bằng code (chưa có phim demo).
